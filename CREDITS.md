## Notation — inspiration, The Unlicense

Project: https://github.com/deathau/Notation-for-Obsidian

Author: deathau. License: [The Unlicense](https://github.com/deathau/Notation-for-Obsidian/blob/master/LICENSE).

Notation's Notion-like gentle reading palette and paper metaphor inspired this project's visual direction. **No Notation CSS, images, or other source assets are copied into this theme.** We acknowledge the source and the public-domain dedication without implying a code dependency.

## Cupertino for Zotero — companion design reference, MIT

Upstream project: https://github.com/shenghuang-123/cupertino-for-zotero

The companion theme [Cupertino Cream for Zotero](https://github.com/vict0rg/cupertino-cream-for-zotero) is itself derived from that MIT-licensed project. We use its recognizable restrained red accent as a shared color direction. **This Obsidian theme does not include Zotero plugin code.**

## Additional study references for v0.1.1 (no source reuse)
