# Submitting Cupertino Cream to Obsidian Community Themes

The [official submission guide](https://docs.obsidian.md/Themes/App%20themes/Submit%20your%20theme) now uses the [Obsidian Community Directory](https://community.obsidian.md) rather than an ordinary repository pull request.

## Repository and release readiness

- [x] Public GitHub repository with fork history and English README
- [x] MIT LICENSE preserving the original Cupertino copyright
- [x] Original design reference and license details documented
- [x] Root theme.css and manifest.json
- [x] GitHub release 0.1.0 with theme.css and manifest.json as assets (after CI completes)
- [ ] **Actual theme screenshot** (recommended 512×288) in `screenshots/cream-light.png` — capture from your installed Obsidian theme. Do not substitute an upstream Cupertino screenshot
- [ ] Visual test in Obsidian in light and dark modes
- [ ] Directory submission through authenticated owner account
- [ ] Address scanner or human-review feedback; approval is managed by Obsidian

## User-owned submission steps

1. Sign in at https://community.obsidian.md using an Obsidian account.
2. Link the GitHub account `vict0rg`.
3. Under Themes, choose New theme and select `https://github.com/vict0rg/obsidian-cupertino-cream`.
4. Use the accurate screenshot path once uploaded, e.g. `screenshots/cream-light.png`.
5. Select Light and Dark supported modes (after testing both).
6. Review developer policies, submit and address feedback.

The theme will only appear under **Settings → Appearance → Themes → Manage** after the directory's review and approval. A GitHub release by itself does not publish it to the official theme gallery.
